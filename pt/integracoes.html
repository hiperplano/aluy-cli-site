ecossistema

Providers e integrações.

A chamada ao modelo vai direto para o provider que você configurou, com a sua chave — sem nada no meio. Aqui está tudo a que o CLI se conecta: os providers de modelo que ele alcança e os projetos abertos com que ele trabalha.

providers de modelos

Para onde vai a chamada ao modelo.

OpenRouter Uma chave só, e dezenas de agentes de vários fornecedores atrás dela. openrouter.ai → Anthropic Modelos Claude — provider direto (sua chave ou OAuth). anthropic.com → OpenAI Modelos GPT — provider direto (sua chave). openai.com → Google · Gemini Modelos Gemini, na API do próprio Google — provider direto (você traz a sua chave). ai.google.dev → DeepSeek Modelos DeepSeek — provider direto; escolha o tier custom para usar um modelo específico deles. deepseek.com → Groq Modelos abertos, com resposta bem mais rápida que a média — provider direto (você traz a sua chave). groq.com → Mistral Modelos da Mistral, da Europa — provider direto (você traz a sua chave). mistral.ai → xAI Modelos Grok — provider direto (você traz a sua chave). x.ai → Ollama Modelos na sua máquina, sem chave e sem rede. É também o programa auxiliar que o modo turbo instala para você. ollama.com →

Nove providers já vêm no catálogo. Fora deles, qualquer serviço que use o mesmo formato da OpenAI serve: declare no providers.json e ele aparece no /provider junto com os outros.

projetos que integramos

O que ele usa, com o que ele fala, e com quem é compatível.

Telegram O seu canal com o agente: ele reporta, pergunta e espera a sua resposta — só nos chats que você autorizar. core.telegram.org/bots → MCP Model Context Protocol — o padrão aberto para conectar ferramentas. modelcontextprotocol.io → mem0 Memória de longo prazo — programa auxiliar (sidecar) opcional. mem0.ai → headroom Mantém conversas longas sem perder o fio — programa auxiliar (sidecar) opcional. github.com/headroomlabs-ai → WezTerm O terminal recomendado para o Aluy CLI. wezterm.org → Node.js A base sobre a qual o CLI roda (Node 20 ou mais novo). nodejs.org → Codex Compatibilidade — se o seu projeto já tem um AGENTS.md, o Aluy lê e obedece, sem você reescrever nada. github.com/openai/codex → Claude Code Compatibilidade — se o seu projeto já tem um CLAUDE.md, o Aluy lê e obedece, sem você reescrever nada. anthropic.com/claude-code →
